## Mochila — backpack-v1.png

```text
Use case: stylized-concept. Asset type: original game menu sprite concept for a Game Boy Advance monster-catching RPG, FireRed UI Remastered. Create ONE isolated adventure backpack, no sheet, no words, no labels, no mockup. Genuine transparent background. The entire object centered with generous clear margins. Crisp, deliberately low resolution pixel art, designed as a 48 by 48 logical-pixel sprite shown enlarged with nearest-neighbor pixel edges. Readable chunky silhouette, clean stepped one-pixel charcoal outlines, restrained three-tone clusters, no smooth antialiasing, no gradients or glow. Three-quarter front view, sturdy crimson flap and front pocket, deep petrol teal side panels and straps, small warm gold clasp, cream highlight accents, subtle turquoise piping. Sympathetic to late-GBA / early Nintendo DS RPG art, a charming functional adventurer's bag rather than a photorealistic product. A few large pockets, meaningful shapes that survive small scale. Restrict visual palette to about 12 colors plus transparency. No characters, no terrain, no shadow plane, no decorative frame, no logos, no text. Make this an original design, not a traced existing sprite.
```

## Pokédex — pokedex-v1.png

```text
Use case: stylized-concept. Asset type: original game menu sprite concept for a Game Boy Advance monster-catching RPG, FireRed UI Remastered. Create ONE isolated open handheld creature encyclopedia device (a Pokedex-like field scanner), no sheet, no words, no labels, no interface mockup. Genuine transparent background. Entire object centered with generous clear margins. Crisp deliberately low resolution pixel art, designed as a 64 by 64 logical-pixel sprite shown enlarged with nearest-neighbor pixel edges. Readable chunky silhouette, clean stepped charcoal outlines, restrained three-tone clusters, no smooth antialiasing, no gradients or glow. Three-quarter front view: open red clamshell field scanner with rich crimson casing, deep petrol-teal dark screen border, a turquoise display with a tiny abstract leaf-shaped specimen indicator (not a real Pokemon), one large cyan camera lens on the upper left, small warm gold navigation buttons and off-white highlights. Match a backpack collection that uses crimson, petrol teal, turquoise, gold and cream. Sympathetic to late-GBA / early Nintendo DS RPG art. Restrict visual palette to about 14 colors plus transparency. Clearly reads as an encyclopedia scanner at tiny scale. No character, no terrain, no shadow plane, no decorative frame, no logos, no typography. Original design, not a traced existing sprite.
```

Los tamaños lógicos y límites de colores del prompt son intención artística. Los archivos
resultantes son RGBA ampliados; su adaptación técnica figura en el plan ARTE y aún está pendiente.
